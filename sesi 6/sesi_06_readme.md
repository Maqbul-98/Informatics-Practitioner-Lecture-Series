# 🛰️ Modul 06: GeoAI Deforestation Alert Driver Classifier

## 📌 Deskripsi
Proyek ini mengklasifikasikan penyebab deforestasi menggunakan kombinasi fitur citra satelit Sentinel-1 (Radar) dan Sentinel-2 (Optik/NDVI) dengan Machine Learning, berdasarkan topik dari Dr. Bart Slagter (Wageningen University).
