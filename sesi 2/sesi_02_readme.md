# ⚡ Modul 02: Parallel Monte Carlo Simulation for HPC

## 📌 Deskripsi
Proyek ini mendemonstrasikan pemrosesan komputasi paralel menggunakan modul `multiprocessing` pada Python untuk mempercepat estimasi nilai Pi dengan metode Monte Carlo, sesuai topik HPC oleh Asst. Prof. Dr. Worawan Diaz Carbalo (Thammasat University).
