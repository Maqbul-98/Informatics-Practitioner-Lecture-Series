# 📊 Modul 01: Automated Data Mining & AI Pipeline

## 📌 Deskripsi
Proyek ini mengimplementasikan alur kerja pengolahan data otomatis (Data Cleaning, Feature Scaling, Model Training, dan Evaluasi) untuk klasifikasi risiko berdasarkan materi "Make Sense of Data with Analysis and AI" oleh Dr. Andria Arisal (BRIN).

## 📊 Metodologi (CRISP-DM)
1. **Business Understanding:** Mengidentifikasi data transaksi/pengguna berisiko tinggi secara otomatis.
2. **Data Preparation:** Scaling fitur numerik dan pembersihan data.
3. **Modeling:** Menggunakan algoritma *Random Forest Classifier*.
4. **Evaluation:** Evaluasi matriks performa dan ekspor laporan ke JSON.
